# Лабораторная работа №8. Базовый CRUD на чистом JS (ES-модули) с json-server.

## Требования

- Node.js 18+
- npm / npx

## Запуск

1. json-server (глобально или локально):

```bash
    npm install -g json-server
    json-server --watch db.json --port 3001
```

2. Приложение 

```bash
    python -m http.server 8080
```
